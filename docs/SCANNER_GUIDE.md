# 扫描枪配置与使用教程

## 设备模式

推荐全部设置为 USB-HID / USB Keyboard / HID-KBW 键盘模式。系统不需要浏览器插件，也不需要串口驱动。

推荐参数：

| 设备 | 模式 | 结束符 | 最大按键间隔 |
| --- | --- | --- | --- |
| Newland HR32/HR3280 | USB HID-KBW | Enter | 80ms |
| 优解 Youjie | USB HID-KBW | Enter 或 Tab | 120ms |
| 通用 USB 扫码枪 | USB Keyboard | Enter 或 Tab | 140ms |

## 使用顺序

1. 打开后台 `/scanner-guide`。
2. 选择扫码枪型号。
3. 设置结束符：Enter、Tab 或 Enter/Tab。
4. 设置当前工位地区，例如广东省/深圳市/深圳一号仓。
5. 用示例码测试解析结果。
6. 进入 `/product-regions` 管理产品与地区映射。
7. 进入 `/scanner` 执行分类装箱、溯源查询、扫码发货。

## 业务对应关系

- 码值包含地区：按码值地区归类。
- 码值不含地区：按当前工位地区归类。
- 产品地区存在：更新扫码次数和最近扫码。
- 产品地区不存在：自动补建产品地区记录。
- 防伪码存在：可执行装箱/溯源。
- 箱号存在：可加入发货单。
- 发货单号存在：可确认发货。


## 一箱一码绑定流程

推荐流程：

1. 先在“装箱管理”创建箱子并生成大码（装箱二维码）。
2. 进入“扫码业务台”，选择“一箱一码绑定”。
3. 先连续扫描产品小码，数量可不限；如填写“每箱产品小码数”，则数量必须一致。
4. 产品小码扫完后，再扫描刚生成的大码（装箱二维码）。
5. 系统识别最后一扫为箱码后自动关联，不再需要固定 10 个小码，也不会把最后一个产品小码误当箱码提交。

## 自动溯源记录

- 扫描防伪码：自动匹配产品、防伪码、批次、生产流程、装箱、物流和查询记录。
- 扫描箱码/装箱二维码：自动同步箱内所有产品小码的装箱链路，并生成箱码查询节点。
- 扫描产品编号：自动生成产品级溯源链，包含产品建档和生产流程节点。
- 后台扫码和消费者扫码都会写入查询节点，便于追溯每次核验。
- 如需补齐历史数据，可在溯源管理中点击“自动同步产品/防伪码溯源”。
