## 📊 技术实现细节

### CSS 动画
```css
@keyframes pulse-dot         // 状态点脉动
@keyframes pulse-warn        // 数字缩放脉动
@keyframes pulse-alert       // 警示图标脉动
@keyframes shimmer           // 骨架屏扫光
@keyframes skeleton-pulse    // 骨架屏呼吸
```

### 交互函数
```typescript
navigateToDetail(key)       // 统计卡片跳转
handleRecentRowClick(row)   // 查询记录跳转
handleAgentRowClick(row)    // 代理商排名跳转
```
