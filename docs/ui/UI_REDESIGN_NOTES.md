## 已完成

- 新增 `src/styles/refined-admin.css` 作为最终主题覆盖层。
- 在 `src/main.ts` 中于原有样式后导入新主题。
- 统一后台的品牌色、字体层级、间距、圆角、阴影和交互状态。
- 重做侧边栏、顶部栏、快捷页签、页面头图区、数据卡片、表格、表单、弹窗和分页样式。
- 优化登录页视觉，并保留原有品牌 Logo 配置能力。
- 适配亮色、暗色及桌面、平板、手机布局。
- 加入减少动态效果的无障碍兼容。

## 回退方式

删除 `src/main.ts` 中这一行即可恢复原视觉：

```ts
import './styles/refined-admin.css';
```
